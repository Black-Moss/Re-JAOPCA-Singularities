# Re:JAOPCA Singularities

[JAOPCA奇点](https://modrinth.com/mod/jaopcasingularities)的高版本移植：这是一个[JAOPCA](https://modrinth.com/mod/jaopca)和[无尽贪婪：重生](https://modrinth.com/mod/re-avaritia)的附属模组，旨在为无尽贪婪添加更多材料的奇点。

包含了[永恒奇点](https://www.curseforge.com/minecraft/mc-mods/eternal-singularity)的复合奇点功能：当奇点数量超过 81 个时，会自动生成一个复合奇点，每个复合奇点相当于原来的 81 个奇点的集合，将所有复合奇点在终焉工作台进行二次合成才能合成出永恒奇点。

极端情况下会生成出 81 个复合奇点，也就是说需要 81x81=6561 个不同的奇点才能合成出一个永恒奇点。

灵感来源于RCXCrafter的[AOBD Singularities](https://www.curseforge.com/minecraft/mc-mods/aobd-singularities)。

注意：奇点模块是自动生成的，如果需要自定义则需要在 JAOPCA 的配置中指定材料或编写标签进行自动生成。
