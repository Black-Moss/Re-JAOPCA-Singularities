# Re:JAOPCA Singularities

[JAOPCA奇点](https://modrinth.com/mod/jaopcasingularities)的高版本移植。

这是一个[JAOPCA](https://modrinth.com/mod/jaopca)和[无尽贪婪：重生](https://modrinth.com/mod/re-avaritia)的附属模组，旨在为无尽贪婪添加更多材料的奇点。

包含了[永恒奇点](https://www.curseforge.com/minecraft/mc-mods/eternal-singularity)的复合奇点功能。

灵感来源于RCXCrafter的[AOBD Singularities](https://www.curseforge.com/minecraft/mc-mods/aobd-singularities)。

请注意，奇点模块是被动的，需要在模组配置中指定材料。
