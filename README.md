# Re:JAOPCA Singularities

A high-version port of [JAOPCASingularities](https://modrinth.com/mod/jaopcasingularities).

This is an addon to [JAOPCA](https://modrinth.com/mod/jaopca) and [Re:Avaritia](https://modrinth.com/mod/re-avaritia), and aims to help add singularities for more materials to Avaritia.

Contains the [Eternal Singularity](https://www.curseforge.com/minecraft/mc-mods/eternal-singularity) The composite singularity function of mods/eternal singularity.

Inspired by [AOBD Singularities](https://www.curseforge.com/minecraft/mc-mods/aobd-singularities) by RCXCrafter.

Note that the singularity module is passive, and materials need to be specified in the module config.
