# Re:JAOPCA Singularities

A high-version port of [JAOPCASingularities](https://modrinth.com/mod/jaopcasingularities): This is an addon to [JAOPCA](https://modrinth.com/mod/jaopca) and [Re:Avaritia](https://modrinth.com/mod/re-avaritia), and aims to help add singularities for more materials to Avaritia.

It includes the composite singularity feature from [Eternal Singularity](https://www.curseforge.com/minecraft/mc-mods/eternal-singularity): When the number of singularities exceeds 81, a composite singularity will be automatically generated.

Each composite singularity is equivalent to a collection of 81 original singularities.

Only by synthesizing all composite singularities together at the End can an Eternal Singularity be created.

Inspired by [AOBD Singularities](https://www.curseforge.com/minecraft/mc-mods/aobd-singularities) by RCXCrafter.

Note: The singularity module is automatically generated.

If customization is required, materials or labels need to be specified in the JAOPCA configuration for automatic generation.
